# 0.7.0 卡面、余额与战斗反馈

发布日期：2026-10-02。包括新手指引，以及本轮显示与反馈修复。

- 卡牌与法宝描述由`CardDescription`按实际游戏字体测量、自动换行并调整字号；取消按字数添加的硬换行。正文水平与垂直居中，所有文字完整显示，保留强化／弱化数字颜色。
- 行囊卡牌页和法宝页的余额保留金额标签自然宽度，避免容器将启用省略的文字压至零宽度。铜钱图标与数字同时显示。
- 烬心环每个己方回合首次受到有效元素伤害时触发，同回合不重复，敌方回合不触发；护盾完全抵消仍触发，完全免疫、直接失血和致命伤害不触发。三级分别获得火能量1／1／2，精与玄另获得1层蓄力。
- 所有伤害效果采用主动“造成”句式，保留选定、固定对手、随机、全体、自伤等目标区别；法宝的“受到伤害时”触发条件保留。
- 双方真气获得／减少均显示对应＋N／－N与徽记、数字的轻微亮起弹动，持续约0.8秒。覆盖回合开始、法宝获得、敌方削减与真气转换；反馈穿过HUD刷新保持连续，不拦截点击与长按。
- 回合衰减、破盾、解除护盾记录为独立减少事件，不播放护盾获得动画。获得护盾与有效护盾抵消伤害保留动画。
- 实际恢复生命使用目标附近的62号绿色＋N、深色底与描边，约1.35秒淡出；角色与召唤物共用，满血无效治疗不显示＋N。
- 修复新手指引提示框覆盖操作区域时，完成按钮会穿透遮罩而失去点击的问题。空法宝仓库也能正常完成介绍。
- 空卡组不启用右侧滚动容器的输入拦截，第一张原生触摸拖入直接交给配组区域；已有卡牌时恢复滚动操作。

无尽规则版本升为5。旧的进行中对局先保存`.rules-v4`备份，保留对手、种子、首次先手、资产和连胜，再从该场开局继续，避免旧烬心环行动记录按新触发条件重放。休整存档直接保留。

`card_layout_ui_test`与对应触屏检查覆盖210个卡牌等级的五种尺寸、90个法宝等级的完整文字、行囊余额，以及真气增减／转换、角色／召唤物治疗和护盾获得／衰减／破除／抵消边界，未加入默认quick。正式APK的完整回归及Android原生验证记录随交付包保存。
