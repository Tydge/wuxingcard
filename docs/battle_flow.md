# 战场流程

## 开局顺序

1. 游戏开始：建立双方角色、卡组及法宝，清空上一局状态。
2. 决定先后手：双方等概率，随机结果由战斗种子决定；界面提示、日志及战报记录先手方。
3. 双方各抽3张起始卡牌：双方六张牌同时飞入各自手牌，单批飞牌约0.43秒。
4. 后手补抽1张起始卡牌：补牌独立展示，之后才结算开局效果。
5. 触发游戏开始时的效果：按先手、后手顺序，分别结算该方开局法宝。玩家观想必须完成选择；效果获得的卡牌全部到手后才继续。
6. 进入先手第一回合：执行正常回合开始流程，真气+1，再抽1张回合牌；展示完成后开放行动。敌方先手时自动进入AI行动。

双方初始金、水、木、火、土灵气均为0，真气各3点；每个己方回合开始真气+1，可保留并点击五行圆圈转化。没有额外开局效果时，先手首回合行动阶段双方手牌均为4张：先手3张起始牌＋1张回合牌，后手3张起始牌＋1张后手补牌。

观澜珠原版在第5步抽1张；精级在第5步观想3；玄级在第5步先抽1张、再观想3。观想候选取自完成起始与后手补牌后的当前牌堆。此时双方己方回合计数均为0，不触发“己方回合首次获得能量”等回合内法宝事件。

## 回合循环

先手第一回合 → 后手第一回合 → 先手第二回合 → 后手第二回合，依此循环。双方各自第一次行动都显示第1回合，敌方先手不再出现第0回合。

回合开始沿用现有结算：重置本回合法宝标志 → 护盾减半 → 按上、中、下槽位结算召唤物的回合开始效果 → 真气+1 → 抽1张牌 → 行动。回合结束沿用现有状态与召唤物结算，再交给对方。

所有开局阶段均检查战斗代次；中途返回或重开后，上一局的选牌与动画不能继续改变新对局。规则层负责阶段和数值，界面只等待并展示各阶段；无界面模拟使用相同规则，不等待动画。

## 验证

`tests/opening_flow_test.gd` 覆盖40个种子的双方先手、逐阶段牌数及能量、重复种子、回合轮转、开局观想与重开。

`tests/opening_deal_test.gd` 用真实渲染覆盖双方起始牌同时飞入、后手补牌、双方观澜珠、开局观想、敌方先手接管与交回玩家、动作锁、动画中重开。双方原版观澜珠共10次抽牌的完整开局（含提示及首回合抽牌）在4秒内完成。
