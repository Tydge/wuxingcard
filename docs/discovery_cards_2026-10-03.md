## 发现N

从指定候选范围中随机提供至多N张不同的卡牌，选择其中一张加入手牌。当前寻珍诀不限定范围，默认使用全部原级卡牌，包括普通牌、召唤牌和发现牌自身。未选择的候选不会入手，不使用抽牌堆、不触发洗牌或疲劳、不增加战斗外库存。手牌上限8，满手牌时选中卡进入弃牌堆。范围不足N时提供全部可用候选；只有1张时直接入手，空范围正常结束效果。

鼠标和触屏均先选择候选，再确认入手；等待选择时暂停后续效果、出牌和结束回合，确认后继续原效果序列，不重复扣费或结算先前效果。敌方和无界面模拟自动评估候选。候选抽样和选择重放使用战斗随机种子；无尽模式记录选择索引，恢复时重现同一张牌。

候选范围通过发现效果的`pool`字段声明，未写即默认全原级卡池。组合条件之间取交集；同一数组内可匹配任意一项。无需为每张发现牌写新结算逻辑。

```json
{
  "type": "discover",
  "target": "self",
  "amount": 4,
  "pool": {
    "elements": ["water"],
    "card_types": ["spell"],
    "max_cost": 4
  },
  "pool_label": "水系普通"
}
```

该例文案为“发现4：一张水系普通卡牌”，提供不高于4费的水系原级普通牌；`pool_label`为简短卡面说明，作者需与实际筛选范围保持一致。

| 字段 | 含义 |
| --- | --- |
| `elements` | 可用五行ID数组：metal/water/wood/fire/earth。 |
| `card_types` | spell普通牌、summon召唤牌，可组合。 |
| `min_cost` / `max_cost` | 卡牌印刷费用的含端点区间，不使用战场费用光环。 |
| `levels` | 等级数组0/1/2，默认仅0；选中牌保留该等级。 |
| `include_ids` / `exclude_ids` | 按原级家族ID纳入／排除，同一家族指定等级均适用。 |
| `effect_types` | 至少含一种指定效果类型，如damage/heal/discover。 |

数组显式为空即没有匹配牌；筛选后的不同卡牌ID不重复抽样。大于单行容量的候选使用横向滚动。关键词说明写“指定范围”，不把发现永久限定为全卡池。
