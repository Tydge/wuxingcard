# 新手指引

首次接触相关界面时，以原位置高亮、箭头、拖动示意与短句说明引导。需要操作的步骤直接使用真实控件：组牌、真气转化、升级预览、法宝标签、装备及法器发动。PC与Android共用指引逻辑，触屏使用更宽的提示面板、大按钮和对应的按住／轻点文案。

## 首次出现的内容

| 场景 | 指引 |
| --- | --- |
| 无尽初始配组 | 左侧选牌、拖到右侧；实时显示已选数量，恰好15张后指向入阵。触屏也可点＋。 |
| 首场战斗 | 固定玩家先手；逐项说明双方生命与灵气、手牌、召唤位、随身法宝（有装备时）、牌库、结束回合与费用；最后实际点属性圈，将1真气转为1灵气。 |
| 首次带法器入战 | 单独指向法器立绘，实际点击发动；需要目标时接续正常选目标操作。护身与灵佩说明为自动触发。 |
| 首次有状态图标 | 指向现有图标，介绍悬停／按住说明与层数。 |
| 首次休整 | 逐处说明集市、行囊、养息、探看与启程。介绍不扣钱。 |
| 首次集市 | 实际点卡牌／法宝查看效果与价格，指向购买按钮；介绍不强制购买。 |
| 首次行囊 | 实际打开卡牌、切换下一等级预览，再介绍淬炼；实际切换法宝并装备。有法宝时点＋或拖到对应槽位，没有法宝时说明槽位后完成。介绍不强制花钱升级。 |
| 非战场首次放大法术 | 属性、对应灵气费用、效果。 |
| 非战场首次放大召唤牌 | 属性、费用、右下角生命、触发与效果。 |
| 非战场首次放大法器 | 属性与类型、左上角冷却、主动使用机制。 |
| 非战场首次放大护身 | 属性与类型、左上角耐久、自动触发与耐久耗尽。 |
| 非战场首次放大灵佩 | 属性与类型、自动效果。 |

放大卡牌介绍适用于藏经阁、测试构筑、无尽组牌、集市和行囊，不用于战场的悬停／长按预览。类型分别记录首次，不会因已看过法术而跳过召唤物或法宝说明。详情介绍结束后继续当前集市／行囊指引。

## 交互与保存

- 介绍某个模块时遮罩拦住其他模块；操作步骤仅放行当前实际操作区域。拖拽示意不替玩家选牌。
- 每段可点「跳过本段」。PC Esc、Android返回键只跳过当前指引，保留正在看的界面；后续段落仍会出现。
- `user://onboarding.json`独立记录各段完成状态、中途步骤与是否已进入首场战斗。退出后恢复；新的无尽挑战不会重复已完成的介绍。不修改卡组、音量偏好或旧无尽资产。
- 首次无尽对局的先手写入战斗日志，重新进入保持一致。普通后续对局继续随机先手；更新前已保存的对局尊重原先手。
- 无尽初始组牌直到正常入阵才完成该段。行囊已到最高等级时跳过下一等级预览；空法宝仓库仍能完成介绍。

## 实现与验证

`data/onboarding_progress.gd`维护进度；`ui/onboarding_controller.gd`根据当前界面和真实控件构建步骤；`ui/onboarding_guide.gd`绘制遮罩、高亮、箭头与拖动示意。战斗与无尽入口仅接入首次先手、进度和真实操作完成信号。

日常相关检查：

```sh
python3 tools/check_project.py --group onboarding
```

该组包含独立存档／先手日志规则，以及PC和触屏真实输入流程，不加入默认4项quick。现有命名规则／界面测试默认关闭指引；这三项使用隔离进度文件显式开启，避免污染玩家存档。所有声音按测试规范关闭。
