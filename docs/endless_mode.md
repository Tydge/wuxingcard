# 无尽模式

2026-09-30，版本0.4.0。仅更新本地源码，未导出试玩包。

## 已确定的玩法

- 开局从全部60种原版卡牌中自选恰好15张，同名最多2张；不能选升级牌或法宝。生命80，灵钱0。选中的20张是初始拥有的全部卡牌。
- 只有胜利才能进入下一关。败北和平局均结束本次挑战，结算连胜与获得的灵钱，保留最高连胜；重新开始不继承财产或升级。
- 每场战斗独立重置生命、能量、状态、召唤物、疲劳、护身耐久和法器冷却。玩家按当前最大生命回满，所有战斗规则与测试模式共用。
- 每关敌人20～30张牌，同名原版／精／玄合计最多2张；至少40%的初始构筑为0～1费，避免随机牌组无法行动。升级可能继续降低费用。
- 第N关敌人最大生命为40＋10×(N−1)，开局回满。每关重新生成身份、卡组与法宝，身份／立绘与构筑独立，不按人物名字或画面指定流派。
- 敌人成长预算为此前全部通关奖励之和：第二关100、第三关210，依此累计。敌人使用玩家相同购买与升级价格；预算不再提升最大生命，不跟踪玩家实际消费。若全部卡牌和装备已经升满，剩余预算不强行变为隐藏加成。
- 休整可免费继续挑战、提升最大生命、逛集市、整理仓库、查看下个对手。继续之前必须有15～30张合法牌组。
- 集市每关有5张随机原版卡牌与2件随机原版法宝。同一次商品列表的原版身份不重复，买走即售罄；下一次胜利后换新。允许付费刷新，每关内连续刷新涨价，下关重置。
- 商品只进入仓库，不自动入组／装备。仓库按实际副本管理，可持有多张同名牌，但构筑仍同名最多2张。法宝保持法器、护身、灵佩各一个槽位。
- 升级逐副本生效：原版→精→玄；移出卡组、卸下法宝不丢失等级。升级预览展示当前和下一级真实效果；先预览下一阶，再确认扣钱。

## 组牌、行囊与休整交互

初始组牌与仓库直接复用测试构筑的 `DeckWorkshop`，使用同一套 `DeckLibraryCard`、`DeckRow`、`DeckDropZone` 和 `CardPageMotion`：五行筛选、平滑翻页、拖入卡组、加号入组与飞牌反馈。鼠标每页12张，触屏每页6张；调整牌组时保留当前页面和列表滚动位置。仓库展示真实持有版本和数量，不能凭空加入升级牌。

点右侧已入组卡牌或已装备法宝即可放大查看并付费淬炼；卡牌同名合并显示，每次升级仅影响一个已入组副本。移出／卸下用独立减号或叉号。放大与收回和藏经阁共用 `CardInspectMotion`；下一级标签只预览，不免费改变等级。开局仅原版，无升级或选法宝入口。

关卡间以一处山间休整场景呈现：点摊位逛集市、点行囊整理、点炉火提升生命、点前方对手探看；保留一个「启程」主按钮。短标签、价格与悬停微光直接对应场景物体，替代原来竖排的大菜单。场景资源与提示词见[休整场景美术](endless_camp_art.md)。

## 初版经济

| 行为 | 灵钱 |
| --- | --- |
| 第N关胜利 | 100＋10×(N−1) |
| 购买一张牌 | 30 |
| 购买一件法宝 | 80 |
| 卡牌原版→精／精→玄 | 40／70 |
| 法宝原版→精／精→玄 | 60／100 |
| 最大生命＋10 | 首次60，以后每次＋20 |
| 刷新集市 | 每关首次20，连续每次＋20 |
| 继续挑战 | 免费 |

这套价格是试玩起点，集中定义于`data/endless_run.gd`，后续按对局体验调整。

## 查看下个对手

初次组牌与每次休整都能查看下一位对手的名字、立绘、生命与卡组总张数。目前只揭示随机3张实际副本，保留其真实升级等级；不公开其他卡牌或法宝。

对手在初始挑战创建／上关胜利时生成并锁定，查看、购物、刷新集市、返回山门及读档均不改变对手。存储全部副本的随机侦察顺序，`scout_count`默认3；未来增加侦察数量会按原顺序多揭示，不重抽已有牌。超过3张时分页，数量超过牌组时最多显示实际全部牌组。

## 进度与战斗恢复

独立存档`user://endless.json`包含最高连胜和当前挑战。组牌、购买、装备、升级、刷新及关卡结算均通过临时文件替换写入；保存失败回滚事务，保留金钱、装备和旧进度。

战斗保留已锁定的对手、战斗种子、行动记录和观想选择。行动在动画／结算前写入；读档时在同一结算器中无动画恢复，重新执行相同AI决策以保留随机数状态。已确认的观想选择按实际索引恢复，未确认的选择重新展示原候选，剩余效果继续结算。中途离开也不会刷新先后手、隐藏牌堆或战斗结果。

## 实现与验证

- `EndlessRun`负责财产、经济、成长、侦察及存档，`EndlessScreen`负责休整、集市、侦察与结算；`EndlessWorkshop`继承测试构筑，仅接入无尽的持有副本、组牌限制与付费动作。
- `BattleManager.start_battle`新增可选的双方生命、敌人卡组与装备参数；其他模式保持默认行为。
- `tests/endless_run_test.gd`覆盖所有交易、构筑限制、固定侦察、生命、平局、磁盘存档、失败回滚及270份敌人构筑。
- `tests/endless_recovery_test.gd`覆盖双方先手、磁盘恢复、开局及主动法宝的未完成／已完成观想、动画前中断。
- `tests/endless_ui_test.gd`与`tests/endless_touch_test.gd`用真实窗口与输入走完整流程，检查初始无法宝、购买不自动装备、付费升级、非法牌组阻止继续与平局结算。截图保存至`work/endless/`。
- 以上检查全部纳入`python3 tools/check_project.py`。
