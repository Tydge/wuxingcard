# 战斗特效素材

2026-09-28 至 29 使用 Codex 内置 imagegen 生成透明底素材，再裁切并缩至最长边 512 px，保存为带透明通道的 WebP。`ui/battle_fx.gd` 负责位移、旋转、渐隐和与原有五行线条的组合；修改尺寸或速度时优先调整代码，不必重画素材。

飞行特效的提示词要求单个横向图形、四周留透明边距、150 px 宽时仍可辨识。逐帧特效的提示词要求 4 列 × 2 行、八个相同中心点的连续动作、每格留透明边距、不出现格线。所有素材均不包含场景、人物、文字、边框或标志。素材生成于内置 imagegen；项目内的四张 WebP 序列图均为 1024 × 512 px，每格 256 × 256 px。中毒和灼伤相邻帧在运行时交叠渐变。召唤物入场只显示一次代码绘制的扩散圆环；回合效果触发不额外叠加圆环，保留立绘轻微动作和飞向目标的效果。
