# 随游戏分发的中文字体

- `NotoSansCJKsc-Regular.otf`：Noto Sans CJK SC，Windows 正文和卡牌说明。
- `NotoSerifCJKsc-Regular.otf`：Noto Serif CJK SC，标题与伤害数字的中文后备字体。
- 来源：https://github.com/notofonts/noto-cjk
- 授权：SIL Open Font License 1.1，原始授权文件随字体和试玩包保留。

Mac 保留已安装的原有字体；跨平台使用打包字体作为后备，避免依赖 Mac 字体名称。没有安装楷体或宋体时，标题及伤害数字使用随包的 Noto Serif CJK SC。
